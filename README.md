# Банковское приложение

Приложение для обработки банковских операций: фильтрации по статусу, сортировки по дате, а также маскировки номеров карт и счетов. Проект демонстрирует работу с датами в ISO-формате, регулярными выражениями и типизацией в Python.

## Особенности проекта

*   **Фильтрация операций:** выборка транзакций по статусу (например, только `EXECUTED`).
*   **Сортировка по дате:** гибкая сортировка списка операций (по убыванию или возрастанию) с корректным парсингом ISO-строк.
*   **Маскирование данных:** безопасное скрытие конфиденциальных данных:
    *   Номера карт: формат `XXXX XX** **** XXXX`.
    *   Номера счетов: формат `**XXXX`.
*   **Обработка ошибок:** валидация входных данных и безопасное преобразование дат.
*   **Генераторы данных:** итераторы для фильтрации транзакций по валюте, извлечения описаний операций и генерации номеров банковских карт в заданном диапазоне.
*   **Надёжность и покрытие тестами:** проект сопровождается набором unit‑тестов на базе pytest, гарантирующих корректность работы всех модулей и устойчивость к некорректным данным.

## Тестирование

Проект покрыт unit‑тестами с использованием фреймворка pytest. Тесты обеспечивают проверку логики, граничных случаев и обработки ошибок.

### Покрытие по модулям

*   *Модуль masks.py (get_mask_card_number, get_mask_account)*

**Корректная маскировка:** проверка стандартных 16‑значных номеров карт и номеров счетов разной длины.
**Валидация входных данных:** тесты на отклонение некорректных форматов пустых строк, строк с пробелами, слишком коротких или длинных значений, наличия букв и спецсимволов (выбрасывается ValueError).
**Проверка типов:** сценарии передачи нестроковых значений (числа, None) проверяется выброс исключения TypeError.

*   *Модуль widget.py (mask_account_card)*

**Автоматическое определение типа:** функция распознаёт префиксы («Maestro», «Visa», «Счет» и т.д.) и применяет соответствующую маску.
**Работа внутри текста:** проверка маскировки номеров, встроенных в строки (например, «Перевод 9999 на Счет 1234…»), при этом остальные цифры в строке не затрагиваются.
**Отсутствие цифр:** если в строке нет подходящего номера, она возвращается без изменений.
**Граничные случаи:** обработка пустых строк, пробелов и строк без цифр.

*   *Модуль processing.py (filter_by_state, sort_by_date)*

**Фильтрация по статусу:** проверка выборки по конкретным статусам (EXECUTED, CANCELED) и несуществующим статусам (возвращается пустой список).
**Значение по умолчанию:** подтверждение, что при отсутствии аргумента state функция возвращает только операции со статусом EXECUTED.
**Пустой список:** проверка поведения функций при передаче пустого списка операций.
**Сортировка дат:** тестирование сортировки по убыванию (по умолчанию) и по возрастанию (reverse=False).
**Обработка некорректных дат:** сценарии с неподходящими ISO‑строками.

*   *Модуль generators.py (filter_by_currency, transaction_descriptions, card_number_generator)*

**Фильтрация по валюте:**
проверка количества отфильтрованных транзакций для разных валют (USD, RUB, несуществующая валюта). 
Проверка обработки пустого списка транзакций и отсутствия совпадений по валюте (генератор корректно завершается без ошибок). 
Проверка, что возвращаемые элементы являются словарями транзакций с правильным кодом валюты. 
**Извлечение описаний:**
проверка содержимого и порядка возвращаемых описаний, 
обработка отсутствующего ключа description (возвращается пустая строка), 
работа с пустым списком и списком из одного элемента. 
**Генерация номеров карт:**
проверка корректности диапазона и формата XXXX XXXX XXXX XXXX (включая крайние значения диапазона — от 0000 0000 0000 0001 до 9999 9999 9999 9999). 
Проверка структуры каждой строки (4 группы по 4 цифры).
Тестирование выброса ValueError при невалидных start и end значениях.
Проверка корректного завершения генератора (StopIteration).

### Инструменты и подходы

**pytest:** основной фреймворк для написания и запуска тестов.
**Параметризация (@pytest.mark.parametrize):** позволяет компактно проверять множество сценариев в одной функции теста.
**Фикстуры (@pytest.fixture):** для подготовки тестовых данных (списки операций, наборы номеров карт и счетов).
**Типизация:** все тесты снабжены аннотациями типов для входных параметров и возвращаемых значений.
**Проверки исключений:** для сценариев с некорректными данными используются контекстные менеджеры with pytest.raises(...).


### Запуск тестов

1. Для запуска всех тестов проекта используйте команду:
    ```
    poetry run pytest
    ```
2. Для получения подробного отчёта о покрытии кода тестами (coverage):
    ```
    poetry run pytest --cov --cov-report=html
    ```
Отчёт сгенерирован в папке **htmlcov/index.html**.

## Установка и запуск

### Предварительные требования
*   Python версии 3.14 или выше.
*   Установленный [Poetry](https://python-poetry.org/).

### Инструкция по установке

1.  **Клонируйте репозиторий**
    ```
    https://github.com/irawildrun/PythonProject.git
    ```
2.  **Активируйте виртуальное окружение и установите зависимости:**
    ```
    poetry install --no-root
    ```
3. **Запуск проекта:**
    Для проверки маскировки номера счета или карты:
    ```
    poetry run python src/masks.py
    ```
    Для проверки логики обработки операций:
    ```
    poetry run python src/processing.py
    ```
    Для проверки генерации и фильтров операций:
    ```
    poetry run python src/generators.py
    ```

## Примеры использования

### 1. Маскировка номера счета или карты (модуль `masks.py`)

Функции принимают строку с цифрами и возвращают замаскированную версию.

```
from masks import get_mask_card_number, get_mask_account

# Маскировка карты (16 цифр)
card = "1596837868705199"
print(get_mask_card_number(card)) 
# Вывод: 1596 83** **** 5199

# Маскировка счета (минимум 4 цифры)
account = "64686473678894779589"
print(get_mask_account(account)) 
# Вывод: **9589
```

### 2. Маскировка через регулярные выражения (модуль `widget.py`)

Функция mask_account_card автоматически определяет тип данных по префиксу и применяет нужную маску.

```
from widget import mask_account_card

print(mask_account_card('Maestro 1596837868705199'))
# Вывод: Maestro 1596 83** **** 5199

print(mask_account_card('Счет 64686473678894779589'))
# Вывод: Счет **9589

print(mask_account_card('Перевод без номера'))
# Вывод: Перевод без номера (строка возвращается без изменений)
```

### 3. Фильтрация и сортировка операций (модуль `processing.py`)

Работа со списком словарей, содержащим банковские транзакции.
```
from processing import filter_by_state, sort_by_date

operations = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
]

# Фильтрация: только выполненные операции
executed = filter_by_state(operations, 'EXECUTED')

# Сортировка: новые сначала (по умолчанию)
sorted_new_first = sort_by_date(operations)

# Сортировка: старые сначала
sorted_old_first = sort_by_date(operations, reverse=False)
```

### 4. Фильтрация транзакций по валюте (модуль generators.py)

Функция-генератор filter_by_currency поочерёдно выдаёт транзакции с заданным кодом валюты.
```
from generators import filter_by_currency, transactions

usd_transactions = filter_by_currency(transactions, "USD")
for _ in range(2):
    print(next(usd_transactions))
```

### 5. Получение описаний операций (модуль generators.py)

Функция transaction_descriptions последовательно возвращает описание каждой транзакции.
```
from generators import transaction_descriptions, transactions

descriptions = transaction_descriptions(transactions)
for _ in range(5):
    print(next(descriptions))

# Вывод:
# Перевод организации
# Перевод со счета на счет
# Перевод со счета на счет
# Перевод с карты на карту
# Перевод организации
```

### 6. Генерация номеров банковских карт (модуль generators.py)

Функция card_number_generator принимает начальное и конечное значения диапазона и выдаёт номера карт в формате XXXX XXXX XXXX XXXX.
```
from generators import card_number_generator

for card_number in card_number_generator(1, 5):
    print(card_number)

# Вывод:
# 0000 0000 0000 0001
# 0000 0000 0000 0002
# 0000 0000 0000 0003
# 0000 0000 0000 0004
# 0000 0000 0000 0005
```
